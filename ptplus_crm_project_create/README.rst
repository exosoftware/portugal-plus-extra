=====================================
Portugal - CRM Project Create
=====================================

This module introduces the following features:

Adds smart buttons on CRM Leads to:

- Open the related Project
- Open the related Tasks

Adds a smart button on Projects to:

- Open the related CRM Lead

Installation
============

Just do it.
