===============================
Portugal - Sale Advance Payment
===============================

This module is designed to complete OCA's Sale Advance Payment in
accordance with Portuguese tax laws. It modifies the behaviour of
the accounts when making advance payments, that are required for
intracommunity down payments.

Installation
============

Install the module with required dependencies:

* add the module to an addons folder, restart Odoo, update the addons list and activate
  it.
